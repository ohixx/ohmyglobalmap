# OhMyGlobalMap

Интерактивная карта для ВПИ-сервера: стороны → страны → редактируемые границы.

- `+` — создать сторону (название и цвет)
- в стороне: добавить страну поиском, кликом по карте, или нарисовать свою территорию
- клик по закрашенной стране — править границы (двигать точки, добавлять вершины, вырезать области)
- данные хранятся в браузере, есть экспорт/импорт в JSON

## Запуск

Статический сайт, нужен любой веб-сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. Подходит для GitHub Pages.

Границы — Natural Earth (через `world-atlas`), карта на Leaflet + Leaflet-Geoman (всё лежит в `vendor/`, без CDN).
